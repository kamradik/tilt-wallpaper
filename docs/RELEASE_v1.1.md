# Tilt 1.1 — страница Kamradik

Живые обои для Android с перспективой и оптическим размытием при наклоне телефона. Можно выбрать свою картинку; приложение работает без интернета.

## В этой версии

- Отдельная страница «Об авторе» с аватаркой Kamradik и кнопкой GitHub.
- Анимированная пиксельная надпись в стиле Minecraft, парящая аватарка и частицы.
- Встроенная тихая музыка: 12% громкости, повтор, пауза и остановка при уходе со страницы.
- Сохранение настройки выключенного звука и обработка аудиофокуса.

## Установка

Скачайте **Tilt-Personal-1.1.apk** ниже, откройте на телефоне и установите. В приложении выберите картинку и нажмите «Установить живые обои». Для страницы Kamradik нажмите «Об авторе ↗» справа от Tilt.

Версию 1.1 можно установить поверх ранее предоставленной 1.0: пакет и ключ подписи сохранены.
