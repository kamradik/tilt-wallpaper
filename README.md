**Tilt** превращает любое фото в живые обои: при наклоне телефона меняются перспектива, резкость и освещение. Эффект создаёт ощущение изображения за наклоняющимся стеклом.

**[Скачать Tilt-Personal-1.1.apk](https://github.com/kamradik/tilt-wallpaper/releases/download/v1.1/Tilt-Personal-1.1.apk)** · [Все релизы](https://github.com/kamradik/tilt-wallpaper/releases) · [Сообщить об ошибке](https://github.com/kamradik/tilt-wallpaper/issues)

## Возможности

- Своя картинка из системного выбора файлов, с сохранением на телефоне.
- Перспектива, оптическое размытие и затемнение от наклона устройства.
- Настоящие живые обои через Android WallpaperService.
- Один графический движок для предпросмотра и рабочего стола.
- Три встроенных процедурных фона и ручной предпросмотр наклона.
- Работа без интернета, без аккаунта и без разрешения на доступ ко всем файлам.
- Остановка датчиков и отрисовки, когда обои не видны.
- Интерфейс в стиле iOS: стеклянная панель, крупные заголовки, пружинные анимации, переключатель и слайдер как в iOS, тактильный отклик.
- Страница автора в виде карточки контакта: размытый фон из аватарки, GitHub и мини-плеер с тихой музыкой.

## Установка

1. Скачай APK из [Releases](https://github.com/kamradik/tilt-wallpaper/releases/latest) на телефон.
2. Открой APK и, если Android попросит, разреши установку для приложения, из которого открыл файл.
3. Запусти **Tilt — свои обои** → **Выбрать фото** (или выбери образец в ряду «Фон»).
4. Нажми **Установить обои** и подтверди выбор в системном окне.
5. Наклоняй телефон. Положение экраном вверх даёт чёткую картинку; наклон меняет перспективу и размытие.

Доступность установки на рабочий стол и экран блокировки зависит от прошивки. В приложении есть переключатель **Ручной наклон** — он работает только в предпросмотре. Касание свободной области экрана скрывает панель, чтобы посмотреть обои целиком.

**Обновление с 1.0:** установи APK 1.1 поверх предыдущего. Имя пакета и сертификат подписи сохранены; удалять приложение не нужно.

## Страница автора

Нажми круглую аватарку справа от названия Tilt. Страница открывается переходом как в iOS: фон — размытая и медленно плывущая аватарка, сверху парит портрет, при прокрутке имя переезжает в навигационную панель. Музыка показана мини-плеером: обложка, индикатор воспроизведения, прогресс и время.

Музыка встроена в APK, играет по кругу на 12% от системной громкости. Кнопка паузы запоминает выключенный звук. При выходе со страницы, сворачивании или переходе в браузер воспроизведение освобождается; при возврате в ту же Activity продолжается с сохранённой позиции. Обои музыку не воспроизводят.

Автор: **[Kamradik](https://github.com/kamradik)**.

## Как работает эффект

Основа — модель неподвижного изображения за стеклом, которое наклоняется относительно наблюдателя. Depth map, нейросеть и сегментация фотографии не требуются.

1. Датчики дают направление гравитации с учётом ориентации дисплея.
2. Углы сглаживаются с постоянной времени 70 мс и масштабируются на 0,75.
3. GPU строит перспективную проекцию для фиксированного наблюдателя на расстоянии 320 мм.
4. Размытие выбирается из заранее подготовленных Gaussian mip-уровней; зазор определяет его силу и затемнение.
5. Когда движение затухает, новые кадры перестают планироваться. При скрытии поверхности отключаются датчики.

Ориентир рендера — около 30 FPS. Изображение приводится к sRGB и ограничивается длинной стороной 2048 px. Подробности, формулы и происхождение модели: **[технический разбор](REVERSE_ENGINEERING_RU.md)**.

## Сборка из исходников

Проверенный путь — **Windows + PowerShell 5.1 или 7 + JDK 17 + Android SDK 36**, без зависимости от Gradle для самой сборки. Нужны SDK Platform 36 и Build Tools 36.0.0; скрипт выбирает самую новую версию Build Tools по `source.properties`, а minSdk, targetSdk и версию берёт из `app/build.gradle`.

```powershell
git clone https://github.com/kamradik/tilt-wallpaper.git
cd tilt-wallpaper
./build.ps1 -Jdk 'C:/path/to/jdk-17' -Sdk 'C:/path/to/Android/Sdk'
```

Скрипт компилирует ресурсы и Java, запускает математические тесты, создаёт DEX, выравнивает и подписывает APK, проверяет подпись. Результат: `dist/Tilt-Personal.apk`.

Для локальной сборки создаётся ключ разработки `.tools/personal-debug.jks`. Ключ опубликованного APK в репозиторий **не входит**. Самостоятельно подписанная сборка не обновит релиз с другой подписью поверх установленного приложения. Сохрани собственный ключ для последующих обновлений своих сборок.

Есть Gradle-конфигурации для Android Studio: AGP 8.13.2, JDK 17, compileSdk 36. Этот альтернативный путь сборки отдельно не проверялся; Gradle wrapper не включён.

### Тесты

`build.ps1` запускает `tests/FoldMathTest.java`: нейтральное положение, эталонная проекция, симметрия, ориентация дисплея, положение экраном вниз, неверные входные данные и диапазон углов.

Дополнительный браузерный тест требует Node.js, Playwright и Chrome на Windows:

```powershell
npm install --no-save playwright
$env:PLAYWRIGHT_MODULE = 'playwright'
New-Item -ItemType Directory -Force analysis | Out-Null
node tests/render-check.cjs
```

Этот тест проверяет компиляцию шейдеров и изображение при четырёх углах. Он не заменяет проверку WallpaperService, аудиофокуса и импорта на реальном Android-устройстве.
